# Support

This page lists where each kind of request about D&D Mapp goes, and what response to expect.

## Where to go

| Request                                                    | Where it goes                                                                                                          |
|:-----------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------|
| A question                                                 | A discussion in [Q&A](https://github.com/dnd-mapp/dnd-mapp/discussions/categories/q-a).                                |
| An idea or proposal                                        | A discussion in [Ideas](https://github.com/dnd-mapp/dnd-mapp/discussions/categories/ideas). Solid ideas become issues. |
| Something broken                                           | The [Bug form](https://github.com/dnd-mapp/dnd-mapp/issues/new?template=1-bug.yml).                                    |
| A vulnerability                                            | The [security policy](SECURITY.md#reporting-a-vulnerability), never a public issue, pull request, or discussion.       |
| Behavior that breaks the code of conduct                   | The [code of conduct](CODE_OF_CONDUCT.md#reporting-a-violation).                                                       |
| A private matter, such as anything involving personal data | An email to [support@dndmapp.nl.eu.org](mailto:support@dndmapp.nl.eu.org).                                             |

Before you open a discussion or a bug report, search for an existing one. When you find one, add your details or a 👍 to it rather than opening a duplicate.

## What to expect

D&D Mapp is a volunteer project with one maintainer, so replies come when time allows, and no response time is promised. [`SECURITY.md`](SECURITY.md#after-you-report) sets its own goals for vulnerability reports.
