# Header

The bar at the top of every page, with the link home and the Menu button. It is the Header component of the design system in Penpot.

<Canvas of={HeaderStories.Mobile} />

## Placing a header

Header is an attribute on `<header>`, so it is the banner of the page. Project the link home around a small logo, and open Mobile menu when the header emits `menuPressed`:

```html
<header dma-header (menuPressed)="mobileMenu.showModal()">
    <a routerLink="/"><dma-logo size="small" /></a>
</header>
```

The header fills the width of the page, and keeps the inline padding of the page, from `--space-page-inline`.

## Focus

The link home takes the size of the logo, and draws the focus ring of Link when it has keyboard focus, since Penpot draws no focus state for it. The Menu button draws the states of a quiet Button.

## Accessibility

The header is the banner landmark of the page. The link home takes its name, "D&D Mapp", from the logo. The Menu button is named by its label, and sets `aria-haspopup="dialog"`, since Mobile menu is a modal dialog. It is 44 px tall, the minimum target size.

## Testing

`HeaderHarness` from `@dnd-mapp/ui-web/testing` reads a header in a test: its look and size, the logo in its link home, the `ButtonHarness` of its Menu button and its attributes, how far the link home and the Menu button sit from its edges, and the focus ring of the link home. `pressMenu()` presses the Menu button.
