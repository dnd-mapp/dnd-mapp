# Logo

The D&D Mapp logo: the mark, the hexagon of the brand, with or without the wordmark. It is the Logo component of the design system in Penpot.

## Placing a logo

Logo is an element. `kind` and `size` pick its variant, and with neither it draws the full logo at the large size:

```html
<dma-logo />

<dma-logo kind="mark" size="small" />
```

The logo renders no link. Header, Mobile menu, and Footer wrap it in the link to the home page, since they know where home is:

```html
<a routerLink="/">
    <dma-logo />
</a>
```

## Kind

`kind` picks what the logo shows, and an unknown value draws the default. Use `LogoKind.Full`, the default, wherever there is room for the name. Use `LogoKind.Mark` where space is short.

<Canvas of={LogoStories.MarkLarge} />

## Size

`size` picks how large the logo draws, and an unknown value draws the default. Use `LogoSize.Large`, the default, in headers. Use `LogoSize.Small` in menus and footers, where the logo sits next to smaller text.

## Colors

The mark keeps the brand colors in both color schemes, since it is brand art. The wordmark takes the default foreground color, so it reads on the page background of either theme.

## Focus

The logo takes no focus, since it is not interactive. The link to the home page around it takes focus instead.

## Accessibility

The logo is an image named "D&D Mapp" in every variant, and it hides the mark from assistive technology, so screen readers announce the name once. A link around the logo takes that name, so the link needs no label of its own.

## Testing

`LogoHarness` from `@dnd-mapp/ui-web/testing` reads the logo in a test: its name, the text of its wordmark, whether it hides its mark from assistive technology, and the size of its mark.
