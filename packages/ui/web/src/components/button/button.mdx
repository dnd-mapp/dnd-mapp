# Button

An action, such as submitting, opening, or toggling. It is the Button component of the design system in Penpot, and Header and Mobile menu hold it.

## Placing a button

Button is an attribute on `<button>` or `<a>`, so the element keeps its native semantics and keyboard behavior. Use `<button>` for an action on the page, and `<a>` with `routerLink` or `href` for one that goes to another page; Button needs no router:

```html
<button dma-button type="button" (click)="save()">Save</button>

<a dma-button routerLink="/maps/new">New map</a>
```

A `<button>` in a form submits it unless it has `type="button"`, as in any form, so give every other button that type.

## Kind

`kind` picks how the button looks. Each kind draws a default, a hover, and a focus state.

### Primary

`ButtonKind.Primary`, the default, marks the main action of a view. Use one primary button per view, so the reader sees at once what the view is for.

## Icons

Place a `dma-icon-*` before the label to lead it, or after it to trail it. The button needs no input for it: it draws the icon 24 px, 8 px from the label, and in the color of the label.

```html
<button dma-button type="button"><dma-icon-plus />New map</button>
```

<Canvas of={ButtonStories.LeadingIcon} />

<Canvas of={ButtonStories.TrailingIcon} />

An icon hides itself from assistive technology, so a button with an icon of its own needs an `aria-label` to name it. It keeps the padding of a button with a label.

```html
<button dma-button type="button" kind="quiet" aria-label="Close"><dma-icon-close /></button>
```

## Width

Below the desktop breakpoint, a button fills a block, column, or grid container, as the GitHub button of Mobile menu does. In a flex row, it keeps the width of its content, as the Menu button of Header does. From the breakpoint up, every button keeps the width of its content.

## Accessibility

The projected content names the button to assistive technology, unless the button has an `aria-label`, and the element keeps its role: `button` on `<button>`, and `link` on `<a>`. Every kind meets the 44 px target size.

## Testing

`ButtonHarness` from `@dnd-mapp/ui-web/testing` reads a button in a test: its text, its look, its size, its focus ring, and its icons with where each one sits.
