# Chip

A label for a status, role, tag, or condition. It is the Chip component of the design system in Penpot, and Card holds it.

<Canvas of={ChipStories.Neutral} />

<Controls of={ChipStories.Neutral} />

## Placing a chip

Chip is an element that projects its label. It is a label, not a control: it takes no focus and emits nothing, so wrap no click handler around it.

```html
<dma-chip kind="status">Planned</dma-chip>
```

<Canvas of={ChipStories.Examples} />

## Kind

`kind` picks how the chip looks. No kind draws a hover or focus state, since a chip is not interactive.

### Neutral

`ChipKind.Neutral`, the default, labels tool names and conditions, such as Spreadsheets or Poisoned. It draws the raised fill with a divider border.

<Canvas of={ChipStories.Neutral} />

### Status

`ChipKind.Status` marks a feature that is not built yet, such as Planned or Concept. It draws no fill, the border of a control, and muted text.

<Canvas of={ChipStories.Status} />

### DM

`ChipKind.Dm` marks a tool meant for dungeon masters. It draws the secondary fill.

<Canvas of={ChipStories.Dm} />

## Accessibility

The projected text carries the meaning, so color is never the only cue: give every chip a label that makes sense on its own. The chip adds no role, so assistive technology reads its text as part of the content around it.

## Testing

`ChipHarness` from `@dnd-mapp/ui-web/testing` reads a chip in a test: its text, its look, and whether it has focus.
