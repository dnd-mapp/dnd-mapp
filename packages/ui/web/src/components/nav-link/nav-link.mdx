# Nav link

A link to a page of the site in its navigation. It is the Nav link component of the design system in Penpot, and Header and Mobile menu hold it.

## Placing a nav link

Nav link is an attribute on `<a>`, so the element keeps the semantics and keyboard behavior of a native link. Add `routerLink` for a page of the app, or `href` for another site; Nav link needs no router. Place the nav links of a menu in a `<nav>`, so assistive technology announces them as navigation:

```html
<nav aria-label="Main">
    <a dma-nav-link routerLink="/features">Features</a>
    <a dma-nav-link routerLink="/roadmap">Roadmap</a>
</nav>
```

## Kind

`kind` picks how the nav link looks. Both kinds are at least 44 px tall, so they meet the minimum target size.

### Bar

`NavLinkKind.Bar`, the default, sits in the bar of the header: it is as wide as its label. Its label is muted until the pointer is over it, or until it marks the current page.

### Row

`NavLinkKind.Row` is a row of a menu, such as Mobile menu: it fills its container, and its larger label takes the default foreground color.

## States

### Hover

The nav link fills its box, and a bar turns its label to the default foreground color.

### Focus

The nav link draws the focus ring outside itself on keyboard focus, and keeps the colors of its default state.

<Canvas of={NavLinkStories.BarFocus} />

<Canvas of={NavLinkStories.RowFocus} />

### Current

The nav link to the current page draws a line in the accent color. A bar turns its label to the default foreground color and draws the line under its label, as wide as the label. A row turns its label to the accent color and draws the line at its start, as tall as the label. The nav link keeps the line and its label color on hover and on focus, so the reader can always tell which page they are on.

Nav link reads the current page from `aria-current="page"` on the link, which also tells assistive technology. With the router, `routerLinkActive` sets it on the link to the active route:

```html
<a dma-nav-link routerLink="/features" routerLinkActive ariaCurrentWhenActive="page">Features</a>
```

## Accessibility

The projected content names the nav link to assistive technology. Write a label of a word or two that names the page, since the label is also all a screen reader announces. Mark the link to the current page with `aria-current="page"` rather than a class, so screen readers announce it as the current page, and color is not the only cue.

## Testing

`NavLinkHarness` from `@dnd-mapp/ui-web/testing` reads a nav link in a test: its text, its colors and font weight, its size, padding, and corners, its focus ring, whether it marks the current page, and its indicator.
